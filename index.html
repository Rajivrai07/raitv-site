Setup Guide

Up & running in 4 steps.

No confusion, no tech headaches. Just follow along.

01

Download & Install

Grab the APK above and install it. Allow "Install unknown apps" if your device asks.

02

Open Addons

Open RAI TV → Settings → Addons. This is where movies & shows come from.

03

Add a Source

Paste this URL and tap Add / Install — Hindi movies, serials & shows:

https://manifest.desitvhub.eu.org/manifest.json

04

Enjoy! 🍿

That's it! Browse the library, pick something, press play.
